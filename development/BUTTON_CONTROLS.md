# Development Button Controls

For the maintained service, see [../stt/docs/BUTTON_CONTROLS.md](../stt/docs/BUTTON_CONTROLS.md). This directory contains earlier experiments; their controls may differ from the main service.

The main service uses WebSocket button commands and an HTML interface. Its current mode-switch behaviour and UI limitation are described in the maintained guide. Use the [repository README](../README.md) for setup.
